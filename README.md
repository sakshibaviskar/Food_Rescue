## 🌟 About the Project

**Food Rescue** is an Android application developed to reduce food wastage and make food donation easier. It helps users donate surplus food, discover available donations, request food, and coordinate volunteer pickups.

The application uses Firebase to manage user authentication and store donation details and in-app notifications.

## ✨ Features

- 🔐 **User Authentication** — Register and log in securely.
- 🍱 **Food Donation** — Share surplus food with essential donation details.
- 🔎 **Find Available Food** — View available food donations.
- 📋 **My Donations** — View donation records.
- 🚴 **Volunteer Pickup** — Manage requested food pickups.
- ✅ **Food Quality Verification** — Check food quality information.
- 📊 **Donation Analytics** — Track donation statuses.
- 👤 **User Profile** — View account information and log out.
- 🔔 **In-App Notifications** — View updates about food donation activities.

| Technology | Purpose |

| Firebase Authentication | User registration and login |
| Cloud Firestore | Store donation data and notifications |

## 🔄 How It Works

1. Create an account or log in.
2. Donate surplus food by entering its details.
3. Browse available food donations.
4. Request food or manage pickup activities.
5. Track donation statuses and view notifications.

## 🎯 Project Objective

To minimize food waste, encourage food sharing, and make surplus food more accessible to people who need it.

## 💻 Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Configure your Firebase project.
4. Add the required `google-services.json` configuration file to the `app/` directory.
5. Enable Email/Password authentication and configure Cloud Firestore.
6. Sync Gradle and run the app on an emulator or Android device.
